# The Fueling Edge player

The Fueling Edge, as an app on the parent's phone. Built from the Youth Athlete Edge player's shell.

- `start.html` home. `fuel.html` the Fuel List with the kid's favorites (every other page uses them).
- `gameday.html` the Game-Day Clock: type the game time, real times fill in, add to calendar.
- `practice.html` early, late or away-day plans. `tournament.html` cooler checklist, gap rule with a text button.
- `recovery.html` the 30-minute recovery timer. `hydration.html` weight to jugs, daily ticks, salt pinch.
- `enough.html` signs checklist. `picky.html` swaps. `recipes.html` 13 recipes with a store list. `week.html` daily ticks and streak.
- `data/fuel.json` holds the Fuel List, the cooler list and the recipes. `fuel.css` and `fuel.js` are shared.

Live at `https://michellemariefit.github.io/fueling-edge-player/`.
